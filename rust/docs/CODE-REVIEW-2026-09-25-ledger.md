- Of these, port_md/{md_stages,nic_prune,nsq_skip} are PARALLEL implementations: the live versions of the same C functions are leaf_funnel/nic.rs and depth_refine.rs, and the port_md copies survive only through agreement tests. A reader grepping for a C symbol lands in the dead copy first.
- Project rule "keep faithful translations even when unreachable" is in tension with signal-over-noise. Proposal that satisfies both: move unwired translations into `src/unwired/` (or behind `#[cfg(any(test, feature = "c_mirror"))]`), and generate an UNWIRED index (like the PORT-NOTE index, with a `--check` drift gate) from deadfns.py so the list can't rot. Then the default build/clippy/doc surface is only live code.
