# Archived documents — evidence, never status

Everything under this directory is a verbatim copy of a document as it stood on
the date in its directory name. It is kept so that a claim can be traced back
to what was known when it was made.

**Nothing here is current, and grep cannot tell you that** — which is the whole
reason this file exists. If a search brought you into
`rust/docs/history/<date>/...`, you are reading a snapshot. Current state is:

- [README.md](../../../README.md) — support, with the gate behind each row
- [IDENTITY-STATUS.md](../IDENTITY-STATUS.md) — parity and open divergences
- [REFUSED-CONFIGS.md](../REFUSED-CONFIGS.md) — generated from the refusal strings

Do not edit an archived file except to add a provenance header, and do not fix
its stale claims: the staleness is the record.
